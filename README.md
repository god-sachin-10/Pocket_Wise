## 🎯 Key Features

- **⚡ Gen Z Visual Identity:** Dynamic neon accents, modern cyber-fintech squircle logo, interactive sparkle micro-animations, and glassmorphic elements.
- **📊 30-Day ₹10,000 Challenge Dashboard:** Real-time available balance, safe daily allowance, days remaining tracker, and projected month-end balance curve.
- **🔮 What-If Decision Simulator:** Test purchases and subscriptions before spending to see instant balance impact, allowance recalculation, and risk forecast.
- **💳 Transaction Management:** Search, filter, categorize, add, edit, and track every single rupee spent.
- **🎯 Savings Goals with Milestones:** Dedicated buckets with target amounts, progress rings, and quick contribution/withdrawal controls.
- **📅 Fixed Commitments & Subscriptions:** Track upcoming recurring bills, toggle active/paused status, and simulate impact on daily allowance.
- **⚠️ Unexpected Expense Scenario Tester:** Pre-configured emergency simulations (medical bill, phone repair, surprise friend trip) with shortfall alerts.
- **❤️ Financial Health Score (0–100):** Multi-factor scoring analyzing savings rate, daily burn rate, buffer ratio, and commitment burden with actionable recommendations.
- **🔐 Demo Authentication & Persistence:** Instant demo login with localStorage state persistence, customizable settings, and reset controls.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Routing:** React Router v7 (`HashRouter` for GitHub Pages SPA compatibility)
- **Icons:** Lucide React
- **Charts:** Recharts
- **Styling:** Custom Vanilla CSS Design System with responsive grid, glassmorphism, and HSL tokens
- **Deployment:** GitHub Pages (`gh-pages` branch + GitHub Actions CI/CD)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/god-sachin-10/Pocket_Wise.git

# Navigate to project folder
cd Pocket_Wise

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

---

## 📦 Build & Deploy

```bash
# Build for production
npm run build

# Deploy to GitHub Pages (gh-pages branch)
npm run deploy
```
